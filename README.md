# Abenezer Samson — Personal Portfolio

Welcome to my personal portfolio website! 👋

This portfolio showcases who I am, my skills, projects, education, and experience as a Software Engineering student and web developer. I built it using only HTML, CSS, and JavaScript without any frameworks because I wanted to improve my frontend skills and understand how everything works from scratch.

## 📁 Project Structure

```text
portfolio/
├── index.html
├── css/
│   └── style.css
├── js/
│   └── script.js
├── assets/
│   ├── images/
│   │   └── profile.jpg
│   ├── icons/
│   └── files/
│       └── cv.pdf
└── README.md
```

## ✨ Features

* Modern glassmorphism UI
* Responsive design for desktop, tablet, and mobile
* Sticky navigation with active section highlighting
* Animated hero section
* Smooth scrolling animations
* Interactive project cards
* Skills with animated progress bars
* Experience timeline
* Statistics counter animation
* Contact form with validation
* CV preview and download
* Google Maps integration
* Dark premium color theme inspired by my profile photo
* Clean, accessible, and semantic HTML

## 📄 My CV

To update my CV, I simply replace the file below:

```text
assets/files/cv.pdf
```

The View CV and Download CV buttons will automatically use the updated file.
